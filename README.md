# Mirent

> Property operations platform for Filipino and foreign unit owners.

## What is Mirent?

A complete, mobile-first, AI-powered property management platform 
connecting hosts, agents, guests, and cleaners in one system.
Designed for the Philippine rental market — built for both local 
and foreign condo owners.

## Stack

- Frontend: React.js
- Backend: Node.js
- Database: PostgreSQL
- Hosting: TBD
