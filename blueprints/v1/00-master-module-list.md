## How to use this list

- One module = one blueprint file in the correct `/blueprints/vX/` folder
- One blueprint file = one developer task
- Never mix modules in one file
- Update status emoji when work begins or completes:
  - 🔲 Not started
  - 🔄 In progress  
  - ✅ Done
  - ⏸️ On hold
